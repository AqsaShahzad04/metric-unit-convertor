# Metric Unit Converter

A clean, browser-based tool for converting between metric units — length, weight, and volume — built with vanilla JavaScript.

## Features

- Convert between common metric units (km, m, cm, kg, g, L, mL, etc.)
- Instant results with no page reload
- Lightweight — pure HTML, CSS, and JavaScript with no dependencies

## Getting Started

Open `index.html` directly in your browser — no build step or server required.

## Tech Stack

HTML · CSS · Vanilla JavaScript
